# Sparrow Manus

一个桌面端的 AI 聊天客户端，基于 Electron 构建，支持 MCP 协议工具调用和知识库管理。

## 功能

**AI 对话**
- 支持 OpenAI 兼容 API 的流式对话
- 展示推理模型的思考过程
- 多会话并行管理，会话数据自动保存

**ReAct 工具调用**
- 基于 ReAct 框架的推理-行动循环
- 智能分析工具依赖关系，支持并行执行
- 最多 10 轮迭代，自动完成复杂任务

**MCP 协议支持**
- 连接多种 MCP 服务器（stdio、SSE、streamableHttp）
- 动态发现服务器提供的工具
- 支持导入 Claude Desktop 的 MCP 配置

**知识库**
- 创建多个知识库，上传文档进行向量化存储
- 语义检索匹配相关内容
- 支持 OpenAI、阿里云、Ollama 等嵌入模型

**提示词优化**
- 系统提示词缓存，加快响应速度
- 从历史对话自动提取示例
- 可配置工具描述详细程度

**界面**
- 终端风格的深色主题
- 自定义标题栏，支持 macOS 和 Windows
- 实时显示工具调用进度和结果
