# Sparrow Manus

桌面端 AI 助手应用，集成对话、知识库、工具调用和代码执行环境。

## 功能

**智能对话**
- 与 AI 进行流式对话，实时显示回复内容
- 支持推理模型，可查看模型的思考过程
- 自动判断何时调用工具，完成复杂任务
- 可配置多个 AI 模型，按需切换

**工具调用**
- 连接 MCP 服务器，扩展 AI 能力
- 支持文件操作、网页搜索、代码执行等工具
- 并行执行多个工具，提高效率
- 最多 10 轮迭代，处理复杂多步任务

**知识库**
- 创建个人知识库，上传 PDF、Word、Markdown 等文档
- AI 自动理解文档内容，支持语义搜索
- 对话时可引用知识库内容，获得更准确的回答
- 支持 OpenAI、阿里云、Ollama 等多种嵌入模型

**Docker 沙箱**
- 在隔离环境中运行代码
- 支持通过 Compose 或 Dockerfile 创建容器
- 适合测试代码、运行脚本、验证程序
- 主进程与沙箱分离，确保安全

**文档导出**
- 将对话内容导出为 Word 文档
- 基于模板生成 PPT 演示文稿
- 支持自定义模板格式

**语音输入**
- 集成阿里云语音识别
- 支持语音转文字输入

## 配置

配置文件：`~/.sparrow-manus/config.json`

数据目录：`~/.sparrow-manus/`
